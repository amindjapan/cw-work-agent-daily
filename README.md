# CloudWorks Work Agent Test

クラウドワークスの公開案件を取得または貼り付けで取り込み、AI/自動化で対応しやすい案件をスクリーニングするテスト版です。

この版では安全のため、応募送信・契約・納品送信は自動化しません。応募文と納品ドラフトを作り、人間が確認してクラウドワークス上で操作する前提です。

## 使い方

```powershell
cd cw-work-agent-test
npm start
```

ブラウザで `http://localhost:4188` を開きます。

## できること

- キーワードで公開案件検索を試行
- 取得できない場合に、クラウドワークスのページ本文やHTMLを貼り付けて解析
- AI/自動化で対応しやすい案件のスコアリング
- 危険・規約違反・低品質になりやすい案件の警告
- 応募文ドラフト作成
- 納品ドラフトの雛形作成
- 生成物を `outputs/` に保存

## 認証について

認証情報は保存しません。ログインが必要な画面に進む場合は、あなたがブラウザでログインして、必要な案件本文をこのツールに貼り付けてください。

## 注意

このツールは補助ツールです。クラウドワークスの規約、案件内容、守秘義務、著作権、クライアントとの約束は必ず人間が確認してください。

## 毎日のおすすめ

`npm run daily` は、ログイン不要の公開検索を複数キーワードで実行し、案件詳細も確認したうえで、自動化しやすい案件を1件選びます。結果は `site/` にスマホ対応の静的ページとして生成されます。

GitHub Actionsの `Daily CloudWorks Pick` は毎日9時17分（日本時間）に同じ処理を実行し、GitHub Pagesへ公開します。Actions画面の `Run workflow` から手動実行もできます。

公開ページへ出す内容は公開案件の情報だけです。`data/`、`outputs/`、`.env`、ローカルログはGitHubへ登録しません。

定期処理が行うのは検索・採点・表示までです。応募、契約、メッセージ送信、納品は自動実行しません。

## Collector の観測記録と公開履歴照合

従来の summary に加えて、実際に観測した全案件と候補ID、前回差分、取得失敗を 内部保存先 `data/collector/` に保存します。同日の再実行も実行単位の履歴を保持します。公開発注者履歴は取得済みの構造化業務資料を明示入力して照合でき、自動プロフィール巡回は未接続です。追加観測と推論は内部確認資料であり、Pages やリポジトリへ自動公開しません。公開コピーは従来ファイルの許可リスト方式です。CI をまたぐ内部資料の永続保存先は未接続です。

出力仕様、互換性、差分の意味、公開履歴の入力方法と未接続範囲は [Collector の観測記録と公開業務履歴](docs/collector-evidence.md) を参照してください。
